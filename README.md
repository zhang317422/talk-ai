# Talk AI

An AI conversation project.

## Getting Started

### Prerequisites

- Python 3.10+
- Node.js 18+

### Installation

```bash
# Clone the repository
git clone https://github.com/zhang317422/talk-ai.git
cd talk-ai

# Install dependencies
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```
